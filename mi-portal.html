Backup & Restore

📤 Export Data

Download all your products, categories, settings and enquiries as a JSON file. Keep this file safe — it's your backup.

📥 Import / Restore Data

Upload a previously exported JSON file to restore your data. This will overwrite current data.

ℹ️ How Backups Work

Your data is stored in Cloudflare KV. Export regularly and save to Google Drive or email to yourself. Every code upload to Cloudflare Pages also creates a deployment restore point — you can roll back from the Cloudflare dashboard under Deployments.
