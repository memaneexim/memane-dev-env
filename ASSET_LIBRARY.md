## HOW TO ADD NEW PRODUCT IMAGE

In `index.html`, find `var IMGS = {` and add:
```js
'Exact Product Name Here': 'https://images.unsplash.com/photo-XXXXXXXXXX?w=500&q=80',
```

To find a good Unsplash photo ID:
1. Go to `unsplash.com`
2. Search for product
3. Click photo → URL contains `/photos/photo-XXXXXXXXXX`
4. Use that ID
